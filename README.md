# gander-skills.github.io

Landing page for the [gander-skills](https://github.com/gander-skills) organization, published at <https://gander-skills.github.io/>.

Skills for Claude Code, including plugins and a marketplace, by gander.

## Development

The site is built by GitHub Pages with [Jekyll](https://jekyllrb.com/). Projects are listed in `_data/projects.yml`; add an entry there to show a new project on the page. Only public repositories belong on the page.

```sh
bundle install
bundle exec jekyll serve
```
